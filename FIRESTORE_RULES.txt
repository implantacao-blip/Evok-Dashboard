⚠️ REGRAS DE SEGURANÇA DO FIRESTORE - IMPORTANTES!

Se os dados NÃO forem salvados, pode ser por falta de regras de segurança.

Siga estes passos:

1. Acesse: https://console.firebase.google.com
2. Selecione: evok-dashboard
3. Vá para: Firestore Database → Aba "Regras"
4. SUBSTITUA TUDO pelo conteúdo abaixo:

---

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Regra: Usuários só podem ler/escrever seus próprios dados
    
    match /transactions/{doc=**} {
      // Ler: só se userId for igual ao uid do usuário logado
      allow read: if request.auth.uid == resource.data.userId;
      
      // Escrever (criar/atualizar): verifica se userId corresponde
      allow write: if request.auth.uid == request.resource.data.userId;
    }
    
    match /goals/{doc=**} {
      allow read: if request.auth.uid == resource.data.userId;
      allow write: if request.auth.uid == request.resource.data.userId;
    }
    
    // Regra para criar documentos sem ainda terem campos
    match /{document=**} {
      allow create: if request.auth != null;
    }
  }
}

---

5. Clique em "PUBLICAR"

PRONTO! Seus dados começarão a ser salvos.

---

IMPORTANTE:
- Sem essas regras = nada é salvo
- Com essas regras = tudo é privado por usuário
- Cada pessoa só vê seus dados
